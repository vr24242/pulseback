# Pulseback Stakeholder Analytics Dashboard

Read-only analytics portal for investors, advisors, and stakeholders. Powered by AI-generated insights.

## Features

- **KPI Dashboard** — GMV, orders, RTO rate, retention, NPS
- **Metrics Deep Dive** — Cohort analysis, carrier performance, product insights
- **Cohort Retention** — Track customer retention curves by acquisition month
- **Geography Analysis** — Orders, RTO rates, and average order value by state
- **AI Insights** — Sonnet-powered weekly briefings and anomaly detection

## Authentication

Stakeholders access via share links generated by merchants:
```
https://analytics.pulseback.app?token={jwt}
```

The JWT includes:
- `shopId` — which store's data to show
- `permissions` — ["read:metrics"]
- `exp` — 30-day expiry

## Environment Variables

```env
VITE_API_URL=https://pulseback.fly.dev/trpc
VITE_JWT_SECRET=your-jwt-secret-here
```

## Development


## Build

```bash
npm run build
```

Outputs to `dist/` for Vercel deployment.

## Deployment

### Vercel

1. Connect GitHub repository to Vercel
2. Set root directory to `apps/stakeholder-analytics-pwa`
3. Set environment variables (VITE_API_URL, etc.)
4. Deploy

```bash
vercel deploy
```

### Custom Domain

Configure in Vercel settings:
- Point `analytics.pulseback.app` → Vercel deployment

## API Routes Used

All via tRPC to `https://pulseback.fly.dev/trpc`:

- `stakeholder.getMetrics` — KPI data (GMV, orders, RTO, etc.)
- `stakeholder.getCohortRetention` — Retention curves by month
- `stakeholder.getGeography` — Orders and RTO by state
- `stakeholder.getBriefing` — AI-powered weekly insights

## Architecture

- **Framework** — React 18 + React Router
- **API Client** — tRPC + React Query
- **State** — React Query caching
- **Auth** — JWT in localStorage (via URL param or manual paste)
- **Styling** — Inline CSS (no build dependencies)

## Known Limitations

- Placeholder charts (Chart.js integration coming)
- Mock data (will be replaced with real DB queries)
- No offline support yet
- JWT auto-refresh not implemented (30-day expiry)
