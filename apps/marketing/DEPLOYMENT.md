# Pulseback Marketing Site — Deployment Guide

## Overview

The Pulseback premium marketing site is a Next.js 14 application with a comprehensive design system and 12+ sections showcasing the AI operations platform.

**Live**: [pulseback.com](https://pulseback.com) (to be configured)

## Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS + custom CSS design system (styles.css)
- **Deployment**: Vercel (auto-deployed on push to `main`)
- **Components**: React 18 with TypeScript

## Local Development

```bash
# Install dependencies
npm install

# Run dev server (port 3001)
npm run dev

# Build for production
npm run build

# Start production server
npm start

# Type check
npm run typecheck
```

## Design System

The entire site uses a cohesive design system defined in `app/styles.css`:

### Colors
- **Brand**: Forest (#0B1F1A) + Lime (#DCEF8A)
- **Surfaces**: Paper, Soft, Cream, Canvas, Ink-Panel
- **Text**: Text-1 to Text-4 (decreasing contrast)
- **Hue Family**: Neon Blue, Green, Cyan, Purple, Pink, Yellow (for OS color-coding)

### Typography
- **Display**: Fraunces (variable font with SOFT axis)
- **Body**: Inter
- **Mono**: JetBrains Mono

### Components
- `Button` (primary, lime, secondary, ghost; sm/md/lg)
- `Card` (compact/default/feature padding; hover effect)
- `Eyebrow` (lime badge with icon)
- `Chip` (colored inline tags)
- `TopNav` (fixed header with nav items)
- `Footer` (5-column + socials)

## Deployment Steps

### 1. Link to Vercel (First Time)

```bash
# Login to Vercel
vercel login

# Link the project
cd apps/marketing
vercel link

# Deploy
vercel --prod
```

### 2. GitHub Auto-Deploy (Recommended)

1. Go to [vercel.com](https://vercel.com)
2. Import project from GitHub: `vr24242/pulseback`
3. Select root directory: `apps/marketing`
4. Add environment variables (if needed)
5. Deploy

**Vercel will auto-deploy every push to `main`.**

### 3. Domain Configuration

1. In Vercel dashboard: Settings → Domains
2. Add `pulseback.com` (or custom domain)
3. Update DNS records (Vercel will show instructions)
4. Point domain to Vercel nameservers

## Troubleshooting

### Build Fails
```bash
npm run build  # Test locally first
npm run typecheck  # Check for TS errors
```

### Styling Issues
- Check `styles.css` for CSS custom properties
- Verify Tailwind classes in `tailwind.config.js` (if exists)
- Use browser DevTools to inspect computed styles

### Components Not Found
- Verify path aliases in `tsconfig.json` (`@/components`)
- Check that component files exist in correct directories
